# NuviPlay TV releases

This repository only hosts release builds of the NuviPlay TV app (working name).

- **Pre-releases** come from the `beta` branch and are offered to users on the Beta update channel.
- **Releases** come from the `main` branch and are offered to everyone.

Each release ships the APKs (per CPU architecture plus a universal build), a `SHA256SUMS` file and `source-<tag>.zip`, the complete corresponding source code of that exact build, as required by the GNU General Public License v3.0 under which the app is licensed. The app is built on Nuvio TV / Nuvio Mobile (GPL-3.0); see the LICENSE and third-party notices inside the source archive.

The app ships with no channels, playlists or content sources; it only plays what you configure.
